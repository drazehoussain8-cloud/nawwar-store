# Images guide · دليل الصور

The template ships with **original flat illustrations** (drawn for this template, demo only) so every page looks complete out of the box. Replace them with photos of **your real products** before selling to a client — real photos convert better.

**How to replace:** save your photo with the **same file name and size** shown below (or change the name in the HTML / `assets/js/products.js`).
**Format & weight:** JPG or WebP, **under 200 KB each** (compress at squoosh.app). Keep the exact ratio so nothing is cropped badly.

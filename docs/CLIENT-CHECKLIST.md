# Client delivery checklist · قائمة تسليم الزبون

Use this each time you adapt the template for a client's store.

**Information to collect**
- [ ] Store name (Arabic + English) and logo
- [ ] WhatsApp number (international format), phone, email, address, opening hours
- [ ] Facebook and Instagram links
- [ ] 6–12 best products: names, prices, sizes, photos (800×1000)
- [ ] Delivery cities/time/fee, return policy, payment method
- [ ] Brand colors (or keep the default)

**Edit**
- [ ] `assets/js/config.js` — name, WhatsApp, contact, social links
- [ ] `assets/js/products.js` — products (delete unused demo ones)
- [ ] `assets/images/` — replace demo illustrations (see `docs/IMAGES.md`)
- [ ] `assets/css/variables.css` — colors
- [ ] Home & about pages — replace testimonials, numbers (2,500+, 98%…), story, timeline, FAQ
- [ ] Offer section — real offer, code word, end date (or remove the section)
- [ ] `docs/PRIVACY-POLICY-TEMPLATE.md` / `TERMS-TEMPLATE.md` — adapt and publish if the client needs them

**Test before sending**
- [ ] Both languages, all 5 pages, on a real phone
- [ ] Every order button opens WhatsApp with the right number and message
- [ ] Menu opens fully; all category chips visible on the Shop page
- [ ] No demo text left (search for "Nawwar", "your-store", "your-domain", "600 000")
- [ ] Domain placeholders replaced in `robots.txt`, `sitemap.xml`, `og:image`

**Honesty note:** only publish real reviews and real numbers for a client's store.

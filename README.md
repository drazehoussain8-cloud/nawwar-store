# Nawwar — Moroccan Online Store Template · قالب متجر نوّار

**EN:** A bilingual (Arabic RTL + English) store website template for people who sell on **Facebook, Instagram and WhatsApp**. 5 pages, 10 animated home sections, mobile-first responsive design, WhatsApp ordering. No frameworks, no build step — open `index.html`.

**AR:** قالب موقع متجر بنسختين (عربية من اليمين لليسار + إنجليزية) لمن يبيعون على **فيسبوك وإنستغرام وواتساب**. 5 صفحات، 10 أقسام متحركة في الرئيسية، تصميم متجاوب يبدأ من الهاتف، والطلب عبر واتساب. بدون مكتبات ولا خطوات بناء — افتح `index.html`.

## Features · المميزات
- Order button on every product opens **WhatsApp with a ready message** (product, quantity, size, price)
- Shop: search, category filter (all categories always visible), sort, wishlist saved in the visitor's browser
- Product page built from one catalog file — add products by editing `assets/js/products.js`
- Contact form that sends the message to your WhatsApp (no server needed)
- Scroll animations, counters, countdown, hover effects (auto-disabled for "reduce motion")
- Full-screen mobile menu; tested from 320 px phones to wide desktops, in both languages
- Inline SVG icons (no icon library); 26 included illustrations
- SEO basics: meta tags, Open Graph, hreflang, sitemap, robots, 404, web manifest
- Moroccan colors, MAD prices, family-friendly / halal-friendly demo content

## Important notes
- The included images are **original demo illustrations**. Replace them with photos of your real products (see `docs/IMAGES.md`).
- Product names, prices, reviews, numbers (2,500+ customers…), phone, email and address are **demo samples** — replace them before publishing. Never publish invented reviews or numbers as real.
- Fonts (Cairo, Poppins, Playfair Display) load from Google Fonts, so the first load needs internet. See `docs/THIRD-PARTY-LICENSES.md` to host them yourself.
